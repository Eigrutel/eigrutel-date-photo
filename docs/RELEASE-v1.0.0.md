# Date Photo v1.0.0 — Première version / Initial release

## Français

Date Photo ajoute la date EXIF au nom des photos et peut les classer automatiquement par année et mois.

- Interface et manuel FR/EN ; fonctionnement local.
- Préfixage seul ou préfixage et déplacement chronologique.
- Aperçu, confirmation, gestion des collisions sans écrasement.
- JPEG, PNG, WebP, TIFF, HEIC/HEIF.
- Arrêt avec Échap ; icône Eigrutel intégrée.

**Si la date contenue dans les métadonnées est erronée, celle du résultat le sera aussi.** Les photos sans date valide restent en place. Sauvegardez vos fichiers avant un classement important.

Télécharger `DatePhoto-1.0.0.exe` pour Windows. Aucun Python à installer pour utiliser l’EXE.

## English

Date Photo adds EXIF dates to photo filenames and can organize them by year and month.

- FR/EN interface and manual; local processing.
- Prefix only, or prefix and chronological filing.
- Preview, confirmation and conflict handling without overwriting.
- JPEG, PNG, WebP, TIFF, HEIC/HEIF.
- Escape to stop; embedded Eigrutel icon.

**Incorrect metadata dates produce incorrect result dates.** Files without valid dates remain in place. Back up your files before major reorganizations.

Download `DatePhoto-1.0.0.exe` for Windows. No separate Python installation is required.
